# Dados

Um arquivo JSON por candidato (ex.: `candidato-a.json`, `candidato-b.json`). Cada item é uma proposta:

```json
{
  "area": "Saúde",
  "titulo": "Título curto da proposta",
  "resumo": "Resumo em linguagem simples, sem adjetivos (propõe X).",
  "trecho_original": "Trecho literal do plano.",
  "pagina": 12,
  "link_pdf": "https://..."
}
```

Áreas: Saúde, Educação, Segurança, Economia, Emprego e renda, Meio ambiente, Moradia, Cultura e esporte.

Todos os resumos são gerados com apoio de IA e revisados por uma pessoa antes de entrar aqui. Licença: CC BY 4.0.
